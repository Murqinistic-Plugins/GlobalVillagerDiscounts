# Tasarım Spesifikasyonu: Minecraft 26.1+ Desteği ve Genel İyileştirmeler

Bu tasarım belgesi, GlobalVillagerDiscounts eklentisinin en son Minecraft sürümü olan **Minecraft 26.1 ve üstü** ile uyumlu hale getirilmesi, Java sürüm hedefinin **Java 25**'e yükseltilmesi ve proje dokümantasyonlarındaki (README.md, MODRINTH.md) hataların temizlenerek kalitesinin artırılması için hazırlanan planı detaylandırmaktadır.

## 📋 Mevcut Durum Analizi ve İyileştirme Alanları

Proje genelinde yapılan tarama sonucunda aşağıdaki uyumsuzluklar ve kalite sorunları tespit edilmiştir:
1. **Minecraft & Java Sürümü:** Eklenti şu anda Minecraft 1.21 ve Java 21'i hedeflemektedir. Minecraft 26.1 ise minimum Java 25 çalıştırıcısı gerektirmektedir.
2. **Dokümantasyon Karakter Hataları (MODRINTH.md):** `MODRINTH.md` dosyasında `` şeklinde bozuk UTF-8 karakterleri mevcuttur. Emojilerin ve madde işaretlerinin düzeltilmesi gerekmektedir.
3. **bStats Bağlantı Hatası (README.md):** README üzerindeki bStats bağlantısı başka bir eklenti olan `AdvancedAFK`'ya yönlendirilmiştir (`https://bstats.org/plugin/bukkit/AdvancedAFK/28505`). Bunun bu projeye (`GlobalVillagerDiscounts`) yönlendirilmesi gerekmektedir.
4. **Sürüm Güncellemesi:** Eklentinin sürüm numarasının `1.3.0`'dan bu büyük altyapı yükseltmesiyle birlikte `1.4.0` sürümüne çıkarılması önerilmektedir.
